## 2024-03-24 - Empty State Discoverability
**Learning:** Empty states without explicit calls-to-action (CTAs) require users to scan the entire UI to find the primary action (e.g., the top-right "Nuovo Link" button), increasing cognitive load, especially for new users.
**Action:** Always include a direct, contextual CTA button within empty states that maps to the primary creation action for that view.
